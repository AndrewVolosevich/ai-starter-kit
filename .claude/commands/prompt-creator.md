Help craft or refine prompts for AI using the CLEAR Framework (Dr. Leo Lo, University of New Mexico): Concise, Logical, Explicit, Adaptive, Reflection. Not every prompt needs all five — choose the mix that fits the task.

## CLEAR Framework

**C — Concise:** Keep prompts brief and focused. Remove filler words and redundancy; keep only what defines the goal and constraints.

**L — Logical:** Use a clear order: context → task → constraints → desired format (if any). Group related requirements; use bullets or steps for multiple conditions.

**E — Explicit:** State exactly what kind of response is needed (list, step-by-step, code, format, length, language). Specify scope and style when it matters.

**A — Adaptive:** Treat the first prompt as a draft. If the result is off, adjust: add examples, narrow scope, or rephrase constraints.

**R — Reflection:** After getting a response, check: Is it relevant, accurate, and complete? Use that to refine the next prompt.

## How to use this command

1. **Draft:** Turn the user's intent into a first prompt using C, L, E.
2. **Review:** Point out where the prompt could be more concise, logical, or explicit.
3. **Refine:** Suggest concrete edits or a revised version.
4. **Reflect:** After the user shares the model's output, suggest tweaks (A + R) for the next round.

## Checklist for a well-crafted prompt

- [ ] **Concise** — No unnecessary words; key task and constraints are clear
- [ ] **Logical** — Order makes sense (context → task → format)
- [ ] **Explicit** — Desired output type, scope, and format are stated
- [ ] **Adaptive** — Clear what to change if the output is wrong
- [ ] **Reflection** — User can judge relevance, accuracy, and completeness of the response
